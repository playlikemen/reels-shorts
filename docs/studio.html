A complete kit for an AI agent to make narrated motion-graphics Reels and Shorts for StackShade, IndexFast, CampusLoop and CraftLayer Studio: the render engine, three brand configurations, a phone-clip tool, the publishing scripts and the written workflow.

Fetch and run

For an agent with the Artifact tool. Every file is published next to this page; MANIFEST.txt lists the paths.

  1. Read MANIFEST.txt from this artifact, then read every listed path into a work folder, keeping the folder structure.
  2. Install: npm install, npx playwright install chromium-headless-shell, python3.11 -m pip install edge-tts faster-whisper numpy. ffmpeg must be on PATH.
  3. Read SKILL.md (workflow) and AGENTS.md (accounts, commands, rules). The element reference is skills/kinetic-explainer-video/SKILL.md.
  4. Write a spec in specs/<brand>/<ID>.json, preview stills, render, verify, then sync.
python3.11 ops/make.py specs/stackshade/SS-101.json --stills 0.3,7,14,21   # look first
python3.11 ops/make.py specs/stackshade/SS-101.json --no-sync              # render + verify
python3.11 ops/make.py specs/stackshade/SS-101.json --sync-only            # Drive + sheet + schedule

The full repository, with 76 reference skills for motion design and distribution, is at github.com/playlikemen/reels-shorts. Syncing and publishing need the owner's Composio connections; rendering does not.
